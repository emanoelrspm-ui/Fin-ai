## Brand & Style

This design system establishes a high-precision, institutional-grade financial intelligence interface. Built for high-frequency financial monitoring, quantitative insights, and AI-assisted portfolio management, it pairs utilitarian functional clarity with an authoritative, deep-surface environment. 

The aesthetic is grounded in a modern corporate minimalism infused with restrained glassmorphic depth. It eschews gratuitous ornament in favor of crisp visual hierarchy, high legibility, and immediate data parsing. Deep obsidian and navy base surfaces reduce eye fatigue across sustained operational sessions, while luminous emerald signals liquidity, balance growth, system health, and affirmative intelligence states. The interface instills unshakeable institutional confidence, speed, and analytical rigor.

## Colors

The color palette is engineered specifically for deep-contrast data environments. 

### Surface Architecture
- **Base Canvas (`#0B0F17`):** The foundational substrate representing zero elevation.
- **Surface Layer 1 (`#111827`):** Recessed containers, panels, and side rail modules.
- **Surface Layer 2 (`#1E293B`):** Active card backgrounds, floating panels, and elevated toolbars.

### Primary Accents & Signals
- **Primary Emerald (`#10B981`):** Applied exclusively to principal calls-to-action, active indicators, positive yields, and AI response highlights.
- **Secondary Teal (`#14B8A6`):** Secondary interactive triggers, data telemetry, and secondary trends.
- **Deep Teal (`#0D9488`):** Selected container fills, focused boundary rings, and contextual badges.

### High-Contrast Neutrals & Text Tiers
- **Text Primary (`#F9FAFB`):** Headlines, metrics, key financial inputs, and system outputs.
- **Text Secondary (`#E5E7EB`):** Body narratives, chat interactions, and form labels.
- **Text Muted (`#9CA3AF`):** Table column titles, historical metadata, timestamps, and placeholder copy.

### Categorical Accents
For data visualization, portfolio distributions, and categorical agent status, use saturated, calibrated spectrum accents built against deep dark grounds:
- **Blue (`#3B82F6`):** Yield-bearing assets, fixed income, system alerts.
- **Purple (`#A855F7`):** Predictive AI projections, algorithmic trades, hedging strategies.
- **Pink (`#EC4899`):** Derivative instruments, leveraged positions.
- **Orange (`#F97316`):** Attention-required flags, volatile instruments, pending authorizations.
- **Slate (`#64748B`):** Inactive instruments, cash balances, historical baseline trajectories.

## Typography

The typographic engine relies entirely on Inter to ensure uncompromised rendering precision, cross-platform ubiquity, and strict mechanical neutrality. 

- **Numeric Data and Metrics:** Always render financial metrics, tabular listings, and time horizons using Inter's tabular lining figure features (`tnum`, `lnum`) to ensure strict vertical alignment across changing asset values.
- **Hierarchy:** Reserve heavy weights (`700`, `600`) strictly for top-line metrics and primary analytical section headers. Body layers rely on regular (`400`) and medium (`500`) weights to preserve clarity over low-light surfaces.
- **Uppercase Labels:** Small labels, status tags, and metadata badges (`label-sm`) require tracking of `+0.04em` and explicit uppercase transformation for instantaneous parsing.

## Layout & Spacing

The layout structure employs a rigorous 12-column responsive fluid grid designed around an 8pt modular cadence, with a micro 4pt baseline for compact component internals.

- **Desktop (1280px+):** 12-column grid, `margin: 2rem`, `gutter: 1.5rem`. The interface is split into a persistent functional nav rail (80px collapsed or 260px expanded), an interactive analytical workspace (8 or 9 columns), and a collapsible conversational AI drawer (3 or 4 columns).
- **Tablet (768px - 1279px):** 8-column layout, `margin: 1.5rem`, `gutter: 1.25rem`. The conversational interface shifts from a persistent side column into a stacked bottom sheet or modal overlay.
- **Mobile (below 768px):** 4-column layout, `margin-mobile: 1rem`, `gutter-mobile: 1rem`. Panels collapse into full-width vertical stacks. Analytical tabs and multi-column comparison tables convert into horizontally swipeable cards.
- **Component Density:** Dense layouts are prioritized for financial tables and agent logs, utilizing `space-xs` (4px) and `space-sm` (8px) for micro margins. General card containers and conversational message groups rely on `space-md` (16px) and `space-lg` (24px) for spatial breathing room.

## Elevation & Depth

Depth in this dark mode environment avoids murky, opaque black drop shadows in favor of translucent obsidian surfaces, structural border containment, and disciplined emerald radiance.

### Layer Stack Architecture
1. **Canvas (Level 0):** Solid `#0B0F17`. Ground plane for screen backgrounds.
2. **Backdropped Glass Surface (Level 1):** `#111827` blended with `80%` opacity, paired with an 8px to 12px backdrop blur. Used for persistent side panels, headers, and standard analytical cards.
3. **Elevated Surface (Level 2):** `#1E293B` blended with `70%` opacity and a 16px backdrop blur. Used for popovers, command palettes, and floating prompt fields.
4. **Overlay / Dialog (Level 3):** `#1E293B` at `90%` opacity, layered over a darkened `#0B0F17` backdrop with a 24px blur.

### Outlines and Border Radiance
- **Standard Structural Borders:** 1px hairline border using `rgba(255, 255, 255, 0.08)`. Never use solid harsh borders.
- **Active Focus & Hover Boundaries:** Transitions boundary opacity to `rgba(16, 185, 129, 0.4)`.
- **Emerald Glow Effect:** Used sparingly on active AI generation states, trade confirmation triggers, or focal cards. Achieved via an ambient shadow: `box-shadow: 0 0 20px -4px rgba(16, 185, 129, 0.25)`.

## Shapes

The design uses balanced, modern corporate corner curvature (`roundedness: 2`). This retains geometric discipline while removing severe industrial sharpness.

- **Base Elements (`0.5rem` / `8px`):** Inputs, buttons, list rows, badges, and inline status chips.
- **Containers (`rounded-lg` / `1rem` / `16px`):** Analytical dashboard cards, chat dialogue cards, chart containers, and modal sheets.
- **Outer Shells (`rounded-xl` / `1.5rem` / `24px`):** Floating command palettes, global application frames, and floating notifications.
- **Full Pill (`9999px`):** Strictly reserved for numerical ticker badges, category tags, and voice-input pills.

## Components

### Buttons
- **Primary:** Background in `#10B981`, label in `#0B0F17` (bold `label-md`). Hover elevates luminosity to `#14B8A6` with an emerald glow (`0 0 16px rgba(16, 185, 129, 0.3)`). Active scale compresses to `0.98`.
- **Secondary / Glass:** Background `rgba(30, 41, 59, 0.6)`, text `#F9FAFB`, 1px border `rgba(255, 255, 255, 0.1)`. Hover shifts background to `rgba(30, 41, 59, 0.9)` and border to `rgba(16, 185, 129, 0.3)`.
- **Ghost:** Transparent background, text `#9CA3AF`, hover text `#F9FAFB` with `rgba(255, 255, 255, 0.04)` fill.

### Input Fields & Prompt Consoles
- **Standard Input:** Height 40px, background `rgba(17, 24, 39, 0.7)`, border `1px solid rgba(255, 255, 255, 0.08)`, border radius `0.5rem`. Text `#F9FAFB`, placeholder `#9CA3AF`. Active focus reveals a 1px ring in `#10B981` paired with a soft halo.
- **AI Prompt Console:** Elevated container with backdrop blur, rounded-lg (`1rem`), containing an auto-expanding multiline text field, action buttons for model controls, and an emerald-accented submission target.

### Cards & Analytical Panels
- Background `rgba(17, 24, 39, 0.75)`, backdrop blur `12px`, border `1px solid rgba(255, 255, 255, 0.06)`, radius `1rem`. Internal header uses `space-md` padding with an integrated metric baseline and top-right trend pill.

### Chips & Badges
- **Status Chips:** Height 24px, pill-shaped (`9999px`), padding `0 8px`. Positive yield uses `rgba(16, 185, 129, 0.12)` fill with `#10B981` text. Neutral/categorical chips use slate, orange, or purple low-opacity tints paired with high-contrast text.

### Checkboxes & Radio Buttons
- 18px dimensions, border `1.5px solid rgba(255, 255, 255, 0.2)`, background `rgba(17, 24, 39, 0.5)`, radius `4px` (checkbox) or `9999px` (radio). Checked state shifts background to `#10B981` with an obsidian `#0B0F17` check/dot indicator.

### Lists & Data Tables
- Table rows have an absolute height of 48px, zero vertical gap, separated by a 1px border `rgba(255, 255, 255, 0.04)`. Hovering a row triggers a subtle background transition to `rgba(255, 255, 255, 0.02)`.

### AI Conversation Streams
- **User Prompt Bubbles:** Right-aligned, background `rgba(30, 41, 59, 0.8)`, text `#F9FAFB`, border `1px solid rgba(255, 255, 255, 0.08)`.
- **AI Response Units:** Full width, transparent background, anchored by a 24px emerald spark icon. Employs inline structured cards for stock charts, financial breakdowns, and scenario analyses.
